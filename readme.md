# Ordenação e Busca de Strings em Python

Este projeto é uma aplicação simples em Python que realiza a **ordenação de uma lista de strings** e permite a **busca de nomes**, retornando se o valor existe e sua posição na lista.

O objetivo deste repositório é documentar estudos e prática de **lógica de programação**, **laços de repetição**, **comparação de strings** e **funções em Python**.

## Funcionalidades

* Ordenação manual de uma lista de nomes em ordem alfabética
* Busca de um nome na lista (case-insensitive)
* Retorno da posição (índice) do nome encontrado
* Impressão da lista ordenada no terminal

## Tecnologias utilizadas

* Python 3

## Como executar

1. Baixe ou clone o repositório
2. Certifique-se de ter o Python instalado
3. Execute o arquivo pelo terminal:

   ```bash
   python nome_do_arquivo.py
   ```
4. O programa irá ordenar a lista e realizar as buscas definidas no código

## Finalidade

Este projeto foi desenvolvido exclusivamente para fins educativos, servindo como registro de prática em **Python**, com foco em **algoritmos de ordenação**, **busca linear** e **estruturação básica de código**.
